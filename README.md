## OS File Management System & Disk Defragmenter Simulator

A cross-platform desktop application built to simulate file management and disk defragmentation algorithms.

---

## Key Features
- **File System Operations:** Custom metadata preservation, tree views, and native drag-and-drop support.
- **Disk Defragmentation Simulator:** Visual representation of sector allocation and block reorganization.
- **User Interface:** Clean and modern GUI designed with Qt framework.

---

##  Built With
- **Language:** C++
- **Framework & GUI:** Qt Framework, Qt Designer
- **IDE:** VS Code / Qt Creator

---

## Getting Started
1. Clone the repository.
2. Open the project in Qt Creator or build using CMake/qmake.
3. Run the application executable.
